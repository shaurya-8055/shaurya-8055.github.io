# Shaurya Shakya, portfolio

Live at **https://shaurya-8055.github.io**

My portfolio as a software engineer and product designer: the products I've designed and built end to end (travafa.com at Travafa, Army Medicine Supplier, SynClock, SnapFloat), how I got here, live builds of my apps you can try inside a phone frame, certificates and skills.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The whole portfolio: one static page with inline CSS and JavaScript, no build step |
| `synclock/` | Product page for [SynClock](https://shaurya-8055.github.io/synclock/), my reminder app |
| `img/` | Photos and screenshots used on the page |
| `certs/` | Certificate PDFs and images |

The live app demos load web builds of my Flutter apps from their own GitHub Pages sites (for example `shaurya-8055.github.io/QUICKGO/`).

## Run it locally
```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

## Design notes
- Pastel palette with one colour per project; type set in Bricolage Grotesque and Instrument Sans (Google Fonts).
- The hero's floating windows can be dragged around, a nod to SnapFloat's floating screenshots.
- Responsive down to phone width, visible keyboard focus, and animations switch off when the system asks for reduced motion.
