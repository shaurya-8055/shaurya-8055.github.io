Under it

Built for the moment the network isn't there

A reminder app that only works online isn't a reminder app. These are the parts that make it hold.

⚡

Exact alarms

AlarmManager fires on the second, through Doze, and re-registers itself after a reboot.

🔌

Offline-first

Create and edit with no connection. Firestore reconciles the moment one returns.

👥

Shared lists

Team reminders with roles, so a group stays on one schedule without a group chat.

🔔

Push that knows

FCM carries teammates' changes; local notifications handle everything on-device.

☁️

Serverless API

NestJS on AWS Lambda, 41 endpoints, with backup and export built in.

🎙️

Hands free

Speak a reminder, hear it read back. Useful exactly when typing isn't.
